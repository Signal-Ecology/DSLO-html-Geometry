## **DSLO HTML Geometry Demonstrations (S–R–σ Invariant Surfaces)**  
This repository contains a collection of DSLO HTML geometry demonstrations illustrating the S–R–σ invariant across multiple runtime simulation surfaces. Each demonstration is provided as a standalone HTML file within its own folder, mirroring the structure of the DSLO Hugging Face Spaces deployment.

The repo serves as a **generic, public‑safe geometry library**, showcasing DSLO coherence behaviors, runtime visualizations, and invariant‑preserving surfaces. These demonstrations include radar‑style sweeps, tensor projections, coherence fields, distortion operators, and other geometry‑driven visual interfaces. All content is static, non‑agentic, and suitable for scientific indexing.

A top‑level `manifest.json` tracks the available HTML surfaces and is updated whenever new geometry demonstrations are added. Zenodo releases provide DOI‑based archival for the entire collection.

### **Purpose**
- Provide a unified home for DSLO geometry demonstration surfaces  
- Mirror HF Spaces in a stable, archival‑ready structure  
- Support scientific indexing and Zenodo DOI releases  
- Offer public‑safe S–R–σ invariant visualizations and runtime geometry examples  

### **Contents**
- Standalone HTML geometry demonstrations  
- Folder‑level READMEs copied from HF Spaces  
- Top‑level manifest for indexing and updates  

### **Exposure Level**
All surfaces are **public‑safe**, static HTML demonstrations.  
No substrate nodes, no NDA content, no runtime engines, no operational DSLO systems.
